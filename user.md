# User Profile & Development Style

## Core Demographics & Focus
- **Current Project:** Web-based PWA Fitness Coach & Autonomous Health/Anatomy System.
- **Goal:** Building a highly modular, responsive, client-side fitness dashboard with Tailwind CSS, Chart.js, and LocalStorage synchronization.

## Preferences & Behavioral Patterns
- **Learning & Coding Style:** Highly pragmatic, hands-on, and iterative. Prefers direct code implementation, complete solutions, and functional architectures over theoretical explanations.
- **Workflow:** Expects clean, production-ready, modular single-file or multi-file HTML/JS applications that can be easily deployed via GitHub Pages.
- **Language:** Turkish (All interactions and code comments should be in Turkish).

## Key System Expectations
- Direct adherence to structured UI layouts (grouped tabs, custom day planning, anatomical heatmap tracking, autonomous agent audits, and tabular data logs).
- Strict execution of user-defined rules without over-simplifying or reverting to generic mockups.
